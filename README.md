# hurricane-request-rescue
CSCE247 Software Project: Hurricane relief request app, Request Rescue

Users will be able to submit requests each with specifications detailing: where they are, what they need, how severe of an issue it is. Other users with valid resources will get pinged with a notification (similar to DoorDash) and they can choose to accept it after being given the information. Users can also request to sign up for shelters where they can receive additional aid. The app will provide live information on the area listing nearby hazards including the hurricane.
