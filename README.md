# hurricane-request-rescue
CSCE247 Software Project: Hurricane relief request app, Request Rescue

Users will be able to submit requests each with specifications detailing: where they are, what they need, how severe of an issue it is. Other users with valid resources will get pinged with a notification (similar to DoorDash) and they can choose to accept it after being given the information. Users can also request to sign up for shelters where they can receive additional aid. The app will provide live information on the area listing nearby hazards including the hurricane.


## Features
- **User accounts:** User log in and out with username and password
- **Submit a request:** Victims submit a request with their location, what they need, and any additional comments
- **Request priority:** The app calculates a priorty for each request based on its severity
-**Alerts to helpers:** users with matching resources are notified of new requests and can choose to accept them
- **Shelter sign-up:** Victims can sign up for a shelter at their preferred location.
- **Live area information:** The app shows nearby hazards, including the hurricane.
- **Saved data:** Users, requests, and shelters are saved so info stay saved between sessions

## Installation
1. Clone the repository:
```bash
        git clone https://github.com/Cakemanm/hurricane-request-rescue.git
```
2. Open project in VS code
3. Make sure Java is installed and download **Extension Pack for Java** in VS Code.
4. Run the code
5. run the driver file.

## Usage
1. log in with username and password
2. Submit a request. Enter your location and details about the request
3. Sign up for a shelter. Pick your preferred location and resources
4. Logout.
